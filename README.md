# Adidas Sales Analysis

📌 Project Overview
This project analyzes Adidas sales data using Microsoft Excel to understand sales performance, product performance, retailer performance, regional sales, and profitability.
The project includes data cleaning, Pivot Table analysis, KPI calculations, and an interactive Excel dashboard.

🎯 Project Objectives
    1).Analyze overall Adidas sales performance
    2).Identify top-performing products
    3).Compare sales across different regions and states
    4).Analyze retailer performance
    5).Understand units sold and total sales
    6).Analyze operating profit and operating margin
    7).Compare different sales methods
    8).Create meaningful KPIs and visualizations
    
🛠️ Tools Used
   1). Microsoft Excel
   2). Pivot Tables
   3). Pivot Charts
   4). Excel Formulas
   5). Slicers
   6). Data Cleaning
   7). Data Analysis
   8). Dashboard & Data Visualization


  🧹 Data Cleaning
        The following data preparation steps were performed:

  1). Checked the dataset for missing values
  2). Checked duplicate records
  3). Verified data types
  4). Reviewed sales and profit values
  5). Organized the dataset for analysis
  6). Prepared the data for Pivot Table analysis


📈 Key Performance Indicators (KPIs)
           The dashboard focuses on important business metrics such as:
  1). Total Sales
  2).  Total Units Sold
  3). Total Operating Profit
  4). Operating Margin
  5). Sales by Region
  6). Sales by Product
  7). Sales by Retailer
  8). Sales by Sales Method
